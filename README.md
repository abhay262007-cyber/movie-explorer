# 🎬 Movie Explorer

## Description

This is a simple movie search web app. You can search for movies and see their details like rating and release date. It uses an API to get movie data.

---

## Features

* Search movies
* View movie rating
* View release date
* Click on movie to see overview
* Simple assistant to guide user

---

## Technologies Used

* HTML
* CSS
* JavaScript

---

## API Used

TMDB API (The Movie Database)

---

## How to Run

1. Download or clone the project
2. Open the folder
3. Open `index.html` in browser
